Provider-neutral design (so the same tests can run on SQL Server through
TEST_DATABASE_PROVIDER): every test registers its own users and asserts only
that user's tasks; case-insensitivity data is ASCII only; tasks in sort tests
are created one fake second apart, so createdAt order is defined and the
provider-dependent id tie-break is never asserted; all times come from the
factory's FakeTimeProvider, formatted with the invariant culture. The lockout
test lives in its own class (own factory and clock) because it moves the clock
15 minutes. The factory's high default rate limit (100000) means none of these
tests can hit 429. No infrastructure change was needed.
